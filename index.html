QUEM SOU EU?

SOBRE MIM

Estudante de Análise e Desenvolvimento de Sistemas (ADS) e Desenvolvedor Front-End em formação, Em evolução para Full-Stack.

Busco sempre aplicar boas práticas de desenvolvimento, com atenção à experiência do usuário e à clareza visual das interfaces, transformar criatividade em código. Estou constantemente criando aplicações web responsivas em HTML, CSS e JavaScript, além do desenvolvimento procuro me desenvolver no âmbito pessoal buscando sempre mais conhecimento.

Atualmente, estou em busca da minha primeira oportunidade como Estagiário de Desenvolvimento. Possuo formação técnica em TI pelo programa Trilhas do Futuro na instituição Gênesis, onde consolidei minha base em lógica de programação, arquitetura sistemas e suporte tecnológico. Crio desde de Landing Page simples até Portfólios, sites comerciais (lojas) até cartão de visita online. Meu objetivo é dominar cada vez mais a parte visual e funcional dos sites, buscando sempre entregar um bom layout, usabilidade e organização no código.

O QUE EU FAÇO?

MEUS SERVIÇOS

1. Desenvolvimento Web

Criação de páginas estáticas e responsivas focadas em capturar a atenção do usuário, estruturadas com HTML5 semântico e estilizadas com CSS moderno para garantir carregamento rápido e boa indexação (SEO básico).

  • HTML5
  • CSS
  • JavaScript
  • Figma

2. Layout Responsivo

Desenvolvimento de layouts que se adaptam a qualquer tamanho de tela (smartphones, tablets e desktops), utilizando técnicas modernas de CSS (Flexbox, Grid e Media Queries) para garantir uma experiência de usuário fluida.

  • HTML5
  • CSS
  • JavaScript
  • Figma

3. Design em Código (Figma to Code)

Capacidade de traduzir com precisão layouts, paletas de cores e tipografias desenhadas no Figma para código limpo em HTML e CSS, respeitando o alinhamento e a proposta visual original do designer.

  • HTML5
  • CSS
  • JavaScript
  • Figma
